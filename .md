STACK & ARCHITECTURE
═══════════════════════════════════════════════════════════════════
- Astro 6 (output: 'static' pour SSG total)
- TypeScript strict
- Tailwind CSS 4 (intégration officielle Astro)
- @astrojs/react pour les islands interactifs uniquement
- @astrojs/sitemap pour la génération automatique du sitemap
- astro-seo (ou implémentation manuelle) pour les métadonnées
- @fontsource-variable/[font] pour les fonts (auto-hébergées,
  RGPD-friendly, pas de FOUT, pas de requête Google externe)
- Astro <Image /> pour TOUTES les images (AVIF + WebP auto)
- View Transitions API d'Astro
- Astro Actions pour le form (server-side avec validation Zod)
- Resend pour l'envoi d'email
- Cloudflare Web Analytics (gratuit, privacy-first, pas de bandeau
  cookies obligatoire) — alternative : Plausible

PRINCIPES :
- 95% de la page = .astro (HTML compilé, zéro JS).
- React islands UNIQUEMENT pour : formulaire, animations complexes,
  compteur 5 jours.
- Directive d'hydratation : `client:visible` partout. Jamais
  `client:load`.
- Pas de UI kit (shadcn, etc.). Composants custom.

   - Internal linking depuis FAQ

5. CORE WEB VITALS (objectif tous verts)
   - LCP < 1.0s (image hero priority + fetchpriority="high")

   - INP < 100ms
